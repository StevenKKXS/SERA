# Attribution and licenses

SERA builds on [RoboMME policy learning](https://github.com/RoboMME/robomme_policy_learning)
and [OpenPI](https://github.com/Physical-Intelligence/openpi). The `src/openpi`,
`src/mme_vla_suite`, `packages/openpi-client`, and simulator adapter code retain
upstream components. Project additions provide agentic planning, task context,
execution-driven harness revision, and RoboMME evaluation utilities.

The code is distributed under [Apache-2.0](LICENSE). Preserve upstream copyright
and license notices when redistributing it. RoboMME's benchmark remains a
separately licensed submodule. [Gemma terms](LICENSE_GEMMA.txt) are retained for
applicable components. Third-party model weights, datasets and simulator assets
remain subject to their respective licenses and download terms.

The resource instructions point to upstream assets; those assets are not
included in this source release.
